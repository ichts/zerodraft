# WRITE_IT_DOWN static site

This directory is the independent writeitdown.app deployment, not the root Zero Draft site. Its approved phase-two brief explicitly chooses vanilla browser JavaScript and both LAMPLIGHT (dark) and DAYLIGHT (light). Do not migrate the root site's Datastar runtime or bone-only palette here.

## Map

- `index.html`: landing and directly addressable `#trial` room. The home-page H1 copy is locked to `We force you to write it down` (no final period) by captain ruling. The landing follows the captain-approved design system ("Paper in light", background A): nav brand plus a `Download for Mac` pill, the H1, the white demo sheet (real `demo.js` preview, at least 60% of the first viewport) with the deck line and the `Give it 60 seconds` room button (`#trial`; `room.js` returns focus to the first `#trial` link), then the core rule, how it works, the facts ledger, the Mac block, the FAQ (details/summary) and a call-back band, then the footer. The JSON-LD keeps `SoftwareApplication` (macOS 14 or later, USD 4.99 `PreOrder` offer while buying is closed, download via `/download/`, no publisher or invented ratings/reviews) and `FAQPage` matching the eight visible questions and answers word for word; every fact on the page must be true of the web room and the Mac app. Faces: Newsreader and Reenie Beanie, the system UI stack for the tool (IBM Plex Mono stays only in the room); `qa/mac.spec.mjs` checks copy, faces, layout, the heading tree and the schema.
- `download/index.html`: the Mac free-trial download page at `/download/` (a directory because the DMG lives beside it in `download/`, uploaded separately), in the same design system as the landing. The DMG link and published SHA-256 use `data-launch` slots. Release requirements are owned by `README.md` "Mac download release".
- `site.css`: shared geometry, room tokens, and landing components. The demo sheet stays at least 60% of the first viewport height. Landing colour, type, spacing, shape, depth, and motion roles are owned by `tokens.css`.
- `tokens.css`: authoritative landing design-system v2 tokens, scoped to `.home`, including background option A and dark-theme overrides. Its header defines font roles. Only the demo sheet uses a shadow; warning and deleted state cards use the semantic wash tokens.
- `theme.js`: appearance preference only, stored under `writeitdown-theme`, the only localStorage key. See `README.md` for the default. The Playwright dark projects set that key.
- `demo.js`: watch-only private messy-draft preview replaying `demo-timeline.mjs` - human-rhythm typing with a visible self-correction and a centered wipe report; also drives the landing card's draining-minute bar and silence meter. Never owns the actual trial; deny feedback fires only in the trial.
- `demo-timeline.mjs`: deterministic seeded typing script (lines, correction beat, pacing) shared by `demo.js` and the qa specs.
- `feedback.js`: shared deny shake and gesture-gated sound; reduced motion suppresses spatial movement.
- `session.mjs`: pure deadline adjudication and Unicode writing-unit count. Earlier deadline wins; ties wipe. See `README.md` for counting semantics.
- `room.js`: transient session owner, native textarea/IME enforcement, upper-third three-visible-line zen viewport, routing, clipboard. Writing never exposes a scrollbar; kept text remains readable. No draft persistence or network transport.
- `privacy.html`, `terms.html`, `support.html`: honest static help/legal pages with the shared theme. Mac copy matches the 3-session trial terms on `mac.html` and `/download/`. `privacy.html#mac` states the trial session counter lives in the app settings file on the Mac and is not sent anywhere.
- `mac.html`, `waitlist.js`: the Mac app page: 3 free sessions, then a USD 4.99 one-time license (2 Macs, 14-day refund) whose checkout is not open. No sentence may require purchase before those sessions. It links the free-trial download page and the web room. Checkout and license delivery steps are each a verified live element (`data-launch`) or a visible pending notice (`data-launch-pending`), never a placeholder link; the waitlist form posts to `/api/waitlist` (`services/waitlist/`) and works without JS via `:target`. The collector's deployment and public POST routing require independent verification; health alone is insufficient. Name no payment provider or license-delivery mechanism until a real test order confirms it. Kept out of the sitemap until sales open. See `README.md` "Mac page release order".
- `release-check.mjs`: `npm run release-check` (add `-- --live` to fetch the URLs), the pre-publish gate. `-- --download` checks only the download page: a real https `.dmg` link and a 64-hex SHA-256, and with `--live` that the served DMG hashes to it. The default also requires live checkout and license slots and fails on missing or placeholder launch inputs, a missing support address, or a mismatch with the app's `Info.plist` price and checkout URL. A pass is not proof of a working sale; opening still needs a real test order and an explicit go. Not shipped.
- `session.test.mjs`: deterministic timing and multilingual-count regressions.
- `qa/input-regression.js`: browser event-path checks, including synthetic IME composition; not an OS input-method test.
- `qa/zen-regression.js`: long multilingual text, fixed zen geometry, scroll containment, and deny-feedback regressions.
- `qa/mac.spec.mjs`: landing, download-page, and mac-page CTA honesty (no live checkout), site-wide link and fragment resolution, release gate CLI fixtures, the waitlist form's JS/no-JS outcomes against both a mocked collector and the real Go collector, and the installer's collector guard.
- `qa/phase4.spec.mjs`, `playwright.config.mjs`: executable eight-project browser acceptance, accelerated clocks, screenshots, and console/network checks. Playwright is test-only; the deployed site has no package runtime.
- `og.png`: 1200×630 light-theme social share card referenced by landing metadata.
- `robots.txt`, `sitemap.xml`, and the Google/Bing verification files: crawl discovery and ownership for the apex site. Keep the sitemap aligned with the indexed canonical pages.
- `journey/journey.mjs`, `journey/serve-local.mjs`: the release journey gate (`npm run journey`, `npm run journey:live`): brand-new visitor, WebKit iPhone + Chromium desktop, continuous videos, named `full-session` (real sixty-second kept text and real clipboard) and independent `silence-wipe` scenarios, real/missing DMG assertions; one `block()` per page section. `--scenarios full-session,silence-wipe` focuses only the room. Preflight serves the real artifact without checksum rewriting. Unasserted sign-in/checkout/payment/post-payment steps require valid checked-in waivers; every executed step rejects newly offered waived controls. Not part of `npm test`.
- `journey/waivers.json`, `journey/waivers.mjs`, `journey/waivers.test.mjs`: explicit absent-feature exemptions approved by captain release decision 2026-10-22 (relayed by main), revocable by the captain. The consumer rejects missing/invalid approvals and newly offered waived controls; focused verification is `node --test journey/waivers.test.mjs`. Features shipping require real assertions and waiver removal.
- `journey/verify-room.mjs`: runs the named room assertions against completion/wipe/copy mutations in worktree-local copies, requires the expected failure on both viewports, then checks the intact site; retains videos and an exit-code/assertion report under `tmp/journey-controls/`. Procedure and Mac evidence requirements live in `README.md`.
- `install.sh`: fixed-target, backed-up deployment inside `/var/www/writeitdown.app/` only. Refuses to install until the waitlist collector's health URL answers `ok`. Creates `download/` and installs only its `index.html`; the DMG is placed there separately.
- `QA.md`: browser acceptance and remaining limits.

The landing follows the approved Paper in light design and `tokens.css`; the room retains the phase-two Room contract. Do not ship `.dc.html` preview scaffolding, frameworks, or design-board runtime. The only analytics is the cookieless Cloudflare Web Analytics beacon, once before `</body>` on each shipped HTML page.

Validate with `node --test writeitdown/session.test.mjs` and `cd writeitdown && npm ci && npx playwright test` (installed Chrome required). The browser suite serves HTTP and covers both themes at 1440x900 and 390x844, normal and reduced motion, with accelerated clocks. The room starts on first input, not entry. Kept text is visible only until exit/reload. Never store or submit writing. The public contact is contact@trefoilstudio.com; do not add other addresses without confirmation.
