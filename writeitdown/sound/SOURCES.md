# Sound sources

Each file in this folder is a slice of a Freesound recording released under CC0 1.0 (public domain dedication,
http://creativecommons.org/publicdomain/zero/1.0/). The licence was read from each sound page on the fetch date.
Attribution is not required by CC0; it is given so every slice can be traced. The slices are band-passed, low-passed
(5.5 kHz keys, 3.6 kHz count, 6 kHz wipe), faded and levelled to a 30 ms window RMS of -33 to -35 dBFS.
