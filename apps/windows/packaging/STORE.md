# MSIX identity for a later Store submission

Nothing here was created in the Microsoft developer account. This is what the captain's reservation fills in.

| Field | Sideload build (now) | Store build (after the name is reserved in Partner Center) |
|---|---|---|
| `Identity Name` | `TrefoilStudio.WriteItDown` | the reserved Package/Identity/Name (the account shows it, e.g. `12345Trefoil.WriteItDown`) |
| `Identity Publisher` | `CN=WID Test Signing` (self-signed, trusted by `install-msix.ps1`) | the reserved `CN=<GUID>` Publisher; the Store re-signs the package |
| `PublisherDisplayName` | `Trefoil Studio` | as the account shows it |
| `DisplayName` / tile name | `Write It Down` | `Write It Down` (the reserved product name) |
| `Version` | `0.2.0.0` (the Store reserves the 4th number: keep it `0`) | increases per submission |
| Visual assets | `assets/` generated by `make_assets.py` from `icon.png`: 44/71/150/310 square, 310x150 wide, 50 store logo, every scale 100-400 and target sizes 16-256 (plated, unplated, light unplated) | same |
| Capability | `runFullTrust` (a classic desktop program in a container) | the Store asks for a one-line justification for this restricted capability |

Build: `scripts/package-msix.sh release` (sideload) or `make-msix.ps1 -Name <reserved> -Publisher <reserved> -PublisherDisplay <name> -NoSign`
for the unsigned package the Store ingests. Certification of an unsigned MSIX is the Store's; this lane did not submit.
