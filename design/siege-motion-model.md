# Siege motion model (landing, desktop) - RETIRED

Status: retired with visual constitution v2. The constitution closes the
graveyard ("no fossil text, no eulogies, no always-on dread"), and the siege -
gutter fossils advancing on the paper during silence - went with it. There are
no fragments left to move, so there is no siege left to run. The `index.html`
siege engine (siegeCapture, siegeAssignDeadline, siegeSynthesize,
siegeBuildReinfPool, siegeStart/siegeBeginPress, siegeFrame, siegeAdvanceReinfs,
siegeKill, siegeRecover, siegeReset) and this model's constants were removed in
the same commit as this notice.

What replaced it: the wash (design/DESIGN.md section 2, `--wash-*` tokens) - a
single linear environment tint from second 5 to second 8 of silence, plus the
step numeral. One slow thing, because it is a fuse.

The full model (deadline progress, pressure aggregation, reinforcement supply,
collective kill, recovery) survives in git history, last live at commit
95f5788. If a future constitution reopens the graveyard, resurrect both the
engine and this file in the same change.
