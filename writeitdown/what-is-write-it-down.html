What is Write It Down?

Write It Down is a writing room for first drafts. You write forward, editing is blocked, and eight seconds of silence in the web room deletes the draft.

The room is for people who edit instead of finishing a first draft. There is no account, no prompt to follow, no history and no draft recovery. The pressure is the product: you either keep writing or you lose the draft.

How does the Write It Down web room work?

The Write It Down web room gives you one 60-second session that starts on your first keystroke. Deleting, pasting, cutting and undo are blocked during the session, so the only way forward is the next word.

How long is a Write It Down Mac session?

A Write It Down Mac session runs from one to thirty minutes, and you pick the length. The app requires macOS 14 Sonoma or later, on Apple silicon or Intel. The download page covers installation.

What does Write It Down cost?

The Write It Down web room is free with no sign-up. The Mac app includes 3 free writing sessions, then a license covers 2 computers for $4.99 once with a 14-day refund. Current purchase details are on the Mac page.

Does Write It Down save my writing?

No. Write It Down saves nothing you write. The web room keeps the draft in the browser tab and the Mac app keeps it in memory on your Mac. See where your writing is kept.

Can I use Write It Down as a notes app?

No. Write It Down has no account, storage or recovery, so a draft exists only in the open session.

What is Write It Down for?

Write It Down forces a first draft out of you. You write forward, you cannot edit, and stopping for eight seconds deletes the draft in the web room.

How do I keep a Write It Down draft?

Copy the text when the clock ends, before you leave the room.
