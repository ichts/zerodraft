How do I delete a draft in Write It Down?

Write It Down deletes the draft for you. Stop typing for eight seconds and the web room deletes the current draft. The Mac app deletes the draft when your chosen silence limit runs out.

The web room warns at 5 seconds of silence and deletes the draft at 8 seconds.

The Mac app offers a Strict 5 s, Standard 8 s or Relaxed 12 s silence limit, with the same warning and deletion. See the Mac and web comparison.

Can I delete one word in Write It Down?

No. Write It Down blocks backspace, selection replacement, paste, cut and undo during a session, so a draft only grows. It enforces the rule to stop the edit loop that keeps a first draft from existing.

How do I keep a draft before Write It Down deletes it?

Copy the draft when the clock ends, before you leave the Write It Down room.

Closing the tab, reloading the page or choosing exit drops the draft, and no server copy exists to recover. See where your writing is kept.

What happens when Write It Down deletes a draft?

Write It Down shows a report that the draft was wiped and keeps the room open. The next keystroke starts a fresh session.

Can I recover a wiped Write It Down draft?

No. Write It Down saves nothing you write, so a wiped, closed or reloaded draft cannot be recovered. Copy the text before you leave if you want to keep it.

Can Write It Down keep a draft open for later?

No. The room keeps a draft only in the session you are in. Closing, reloading or wiping the room ends it.
