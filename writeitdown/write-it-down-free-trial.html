How does the Write It Down free trial work?

The Write It Down free trial costs nothing and needs no card. The web room is free with no sign-up and no session limit. The Mac app includes 3 free writing sessions that count once you type the first character.

A Mac session starts when you type, not when you open the app. Installing the app, reading the screen, changing the theme or leaving the room idle spends nothing, so the first session waits until you write.

What happens after the 3 free Write It Down Mac sessions?

Writing in Write It Down for Mac then needs a license. The license costs $4.99 once for 2 computers, with a 14-day refund and no subscription. See the Mac page for current purchase details and license delivery.

Does the Write It Down web room have a session limit?

No. The Write It Down web room has no session limit and no account, and it stays free and complete. A Mac session behaves the same way: the draft lives in the session and nothing is uploaded.

Does the Write It Down trial upload my writing?

No. Write It Down uploads no draft from the web room or the Mac app. The Mac app stores the used-session counter in its settings file on your Mac, and that counter is not sent anywhere. License checks send license details and a random installation identifier, never your writing. The macOS privacy section covers what leaves your Mac.

Where can I download the Write It Down Mac trial?

The Write It Down download page provides the free Mac trial, the disk image checksum and the install steps.

How many free sessions does Write It Down for Mac include?

3. Each session counts once you type its first character.

Does the Write It Down free trial need a card?

No. The trial has no checkout, no card and no account. Download the disk image from the download page and open it.

What spends a Write It Down Mac session?

The first character spends a session. Opening the app or leaving it idle spends nothing.
