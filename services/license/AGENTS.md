# License service module

`README.md` owns the HTTP, Mac token and operational contract. `service.go` owns provisional signed callback processing, SQLite licenses and activations, and offline Ed25519 tokens; `migrations.go` upgrades local callback receipts for replay-conflict checks. `http.go` owns bounded request admission, proxy-address trust and the fail-closed checkout route. `capture.go` owns opt-in bounded, atomic private callback evidence and expiry cleanup, before verification and without granting authorization. `main.go` owns test-only configuration, key-file checks, capture configuration, loopback binding and shutdown. `admin.go` owns offline manual revocation. Tests cover local signed fixtures and a real local HTTP listener, not provider integration. `deploy/README.md` and its templates prepare an authorized test deployment; they do not deploy anything.

`README.md` records the dedicated Trefoil Studio merchant configuration and pending evidence. The old shared-store fallback is withdrawn. The canonical callback route is `/api/v1/webhooks/waffo`; the merchant-side TEST update remains unverified. The supplied official documentation's timestamp-prefixed signature and event envelope differ from this skeleton; the verifier remains unchanged. Require genuine TEST headers and raw bytes through a restricted channel before claiming provider compatibility. Private captures are unverified evidence, never ordinary logs or public fixtures. The README defines their exact byte/header representation, storage limits, permissions and retention. Buyer credential mapping and actual signed completion/refund payloads remain unverified. Checkout stays unavailable until the provider adapter and genuine TEST purchase/refund are proven. Never infer them from fixtures. The client is a free download with three trial sessions and a one-time license unlock; the paid path depends on genuine TEST checkout, buyer credential delivery, activation and refund-revocation evidence. No production deployment is authorized by that priority. This module never contacts Waffo or stores application drafts. Keep private keys and order credentials out of logs, fixtures and source. Run `go test ./... && go vet ./... && go build .` here, with `go test -race ./...` for request/storage changes. Follow the README's genuine test-order gates before enabling payments.
