First Line logo concepts

Eight SVG directions. Current favicon is included only as a reference. Each option is shown at 64, 32, and 16-ish sizes so the favicon problem is visible.

Current reference

Two text lines plus cursor. Clear and usable, but a little generic and static.

01 Margin Cursor

Closest to the current mark, but adds the red-brown margin line: paper, draft, cursor, discipline.

Safest evolution

02 Forward Only

The first draft can only move right. More explicit, almost like a rule stamped into the icon.

Most literal

03 Constraint Box

A page as a hard boundary. Good if the brand should feel stricter and more native-tool-like.

Most app-like

04 Vanishing Draft

The old lines fade; only the current line survives. Captures the danger mechanic without alarm red.

Most product-specific

05 FL Cursor

A compact monogram: F/L structure with the cursor as the right spine. Stronger as app icon.

Most brandable

06 Pressure Lines

Lines narrow under pressure until the cursor is all that remains. Feels like a forge, not a notebook.

Most severe

07 Sixty Seconds

Timer arc plus current line. It says “timed writing” immediately, but is less literary.

Most explanatory

08 Irreversible Edge

Text hits a cursor, then an arrow edge. The page pushes forward and refuses retreat.

Most directional
