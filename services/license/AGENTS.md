# License service module

`README.md` is the operational and HTTP contract. `service.go` owns signed Waffo event processing, SQLite licenses and activations, HTTP handlers, and offline Ed25519 tokens; `main.go` owns environment and key-file configuration; `admin.go` owns the offline manual revoke command; `service_test.go` exercises the test-mode contract with fake signed events. This module never contacts Waffo or stores application drafts. Keep private keys and order credentials out of logs, fixtures, and source. Run `go test ./...` and `go vet ./...` here after changes. Production webhook payload compatibility and receipt order-ID visibility require a real test-order check before launch.
