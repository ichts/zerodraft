# Write It Down - WID world table / 世界观表

Design rulebook v3, design process step 1 (world table / 世界观表). One table per surface. Written for agents: read a cell, then open the cited line. Cells are verified against the current code unless marked `待证` (inferred, with the one thing needed to verify it). `D-0xx` ids are in `docs/wid-decisions.md`; `Mac case N` is a row of `docs/wid-mac-behavior.md`; `SYNC N` is a row of `apps/windows/SYNC.md`.

The shared world: a room with one paper and one clock. The user stands at the paper with eyes on the writing line (Mac and Windows 33% anchor, D-070; web trial 35%, D-025). Nothing is saved (D-062).

## Evidence and open items / 证据与待办

Corrections to `wid-motion-audit/report.md` table C:
- Page change confirmed on all three surfaces (A `room.js:301-311`, B `RootContainerViewController.swift:46-62`, C `app/view.go:38-47`). Whether the paper should grow is a design decision no D-id records.
- Mac paper texture: synchronous first paint confirmed; the 0.1 s is a comment only. Windows measured 350-390 ms with an 80 ms flat window (`SYNC.md:55`).
- Decorative bitmaps: no explicit written rule. Q-01 (`ui-quality.md:29`), `design/DESIGN.md:109` and Mac case 62 are the nearest sources; no `<img>` or illustration ships on any surface.
- The wipe and kept strings in the audit were the root landing's. The web room and the apps use `You stopped.` / `Draft deleted.` and `You wrote it down.` with `N minutes. M words.` (D-029, D-062, D-095).
- "No second dark mode" is wrong for these surfaces: all three carry a light and a dark paper (D-093, SYNC 28 at `SYNC.md:66`). That ban belongs to the root landing only.

Still `待证`, each with its one need:
1. Paper grows or is swapped as the intended behavior (all surfaces): a captain decision entry.
2. Web room first frame untextured or not: frame-by-frame capture of `#trial` entry.
3. Mac texture cost 0.1 s: timed `PaperField.sheet` run at 2x.
4. Windows copy failure path (and the Windows flat 80 ms): code change owned by the Windows port, out of scope here; tracked by SYNC 11 and SYNC 17.
5. Explicit ban on decorative bitmaps and illustrations: a new decision entry.
